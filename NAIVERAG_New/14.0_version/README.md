# 智能法律问答系统

基于 RAG（检索增强生成）+ Agentic RAG 技术的智能法律服务平台，支持法律咨询、合同审查、文书生成、风险评估等核心功能。

---

## 项目概述

本项目是一个面向法律领域的智能问答系统，集成以下核心能力：

- **RAG 检索增强**：基于混合检索（向量 + BM25）+ 重排技术
- **多模型支持**：支持本地模型（Qwen3 系列）和云端 API 灵活切换
- **Agentic RAG**：基于 LangChain Agent 实现智能工具调用和多轮对话
- **模型微调**：支持基于法律数据集（DISC-Law）微调专用模型
- **外部数据源**：集成得理开放平台 API 提供法规和案例检索

---

## 核心特色

### 1. 混合检索系统
- 向量检索 + BM25 关键词检索
- 支持动态配置检索权重
- 集成重排模型提升相关性

### 2. 多模型管理
- 统一模型管理接口
- 支持本地模型：Qwen3-4B、Qwen2.5-1.5B、Qwen3_0.6B
- 支持云端 API：阿里云百炼
- 支持**微调模型**：基于法律数据集微调的专用模型
- 运行时动态切换模型

### 3. Agentic RAG 架构
- 使用 LangChain Agent（CONVERSATIONAL 模式）
- 自动决策工具调用（法律检索、案例检索等）
- 支持多轮对话，记住上下文
- **无外部数据时自动基于 LLM 知识回答**

### 4. 模型微调能力
- 基于 DISC-Law 数据集进行 SFT 微调
- 支持 LoRA/QLoRA 低显存微调
- 可训练法律咨询、合同审查、文书生成等专业能力

### 5. 数据来源声明
- 响应中自动声明数据来源
- 区分"外部数据"和"LLM知识"
- 符合法律服务的合规性要求

### 6. 完整的 Agent 功能
| 功能 | 说明 |
|------|------|
| 法律咨询 | 回答劳动法、合同法等问题 |
| 合同审查 | 识别劳动合同风险条款 |
| 文书生成 | 生成仲裁申请书、起诉状、借条等 |
| 风险评估 | 评估诉讼胜诉概率和风险 |
| 流程指引 | 劳动仲裁、工伤认定等流程 |

## 技术亮点

### 1. Agentic RAG
使用 LangChain CONVERSATIONAL Agent，自动调用工具，支持多轮对话。

### 2. 无数据时的智能回答
系统自动识别外部数据是否可用，无数据时基于 LLM 知识回答，并在响应中声明数据来源。

### 3. 数据来源声明示例
```
⚠️ 声明：本答案基于法律知识生成，仅供参考，具体情况请咨询专业律师。
```

### 4. 混合检索配置
```python
RETRIEVAL_MODE = "hybrid"  # 混合检索
HYBRID_WEIGHTS = (0.2, 0.8)  # BM25:向量 = 2:8
RERANKER_ENABLED = True  # 启用重排
```
